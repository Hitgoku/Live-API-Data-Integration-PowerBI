
# Live API Data Integration: Global Development Dashboard

## 1. Project Overview

This project analyzes global economic, social, environmental, and healthcare indicators using data from the World Bank API.

Python and Power BI are used to retrieve, process, analyze, and visualize development indicators across countries and regions.

The project includes API integration through Python scripts, statistical visualizations, data modelling, and an interactive Power BI dashboard.

## 2. Project Objectives

- Integrate global development data using the World Bank API.
- Retrieve and process data using Python.
- Analyze economic and social development patterns.
- Compare healthcare expenditure across regions.
- Investigate relationships between internet access, immunization, and unemployment.
- Analyze poverty reduction progress.
- Explore relationships among healthcare indicators.
- Evaluate government health spending against life expectancy.

## 5. Project Workflow

1. Retrieve selected indicators from the World Bank API using Python.
2. Process API responses and prepare datasets.
3. Load and organize data in Power BI.
4. Use Python scripts within Power BI for API integration and selected visualizations.
5. Create analytical measures and data relationships.
6. Develop interactive dashboard visualizations.
7. Interpret patterns and generate business insights.

## 6. Business Questions

1. Understand the overall economic and social landscape.
2. Compare health expenditure across regions.
3. Analyze trends in key socio-economic indicators.
4. Evaluate internet access versus immunization rates.
5. Assess internet access versus unemployment.
6. Identify the bottom 10 countries in poverty reduction.
7. Identify the top 10 countries in poverty reduction.
8. Examine relationships among health indicators.
9. Investigate government health spending versus life expectancy.
